# Portfolio Développeur Web

Ce projet est le portfolio de **Malika Salhi**, développeuse web full stack junior, spécialisé en **React**, **Node.js** et **MongoDB**.

## Description

Le portfolio présente :

- Une page d'accueil avec **Hero** et **Présentation**
- Les **compétences techniques et humaines**
- Les **projets réalisés**
- Une **timeline** de parcours
- Une section **Contact** avec formulaire et liens vers GitHub/email

Le site est développé avec **React**, et optimisé pour le **mode sombre**.

## Installation

```bash
git clone <url-du-projet>
cd portfolio
npm install
npm run dev
